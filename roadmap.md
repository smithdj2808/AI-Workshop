# Roadmap

## What this is
This is a task list for students juggling multiple courses. It groups tasks by class and shows what's due soonest across all of them, instead of one flat list.

## What Done means
A student can create an account, log in, add tasks tagged with a course name and due date, see them grouped under course headings with the nearest due date easy to spot, and return later to find everything unchanged.

## Slices
1. Sign up and log in | done-criteria: person creates an account and lands on a non-signup page; person logs out and back in with the same credentials; wrong credentials show an error and keep them on the login page; visiting the dashboard URL while logged out redirects to login | status: ACTIVE
2. Add and manage tasks tied to a course | done-criteria: adding a task with a title and course name shows it labeled with that course; marking a task complete visibly changes it; tasks and their complete/incomplete state survive a refresh or re-login; deleting a task removes it permanently | status: pending
3. Group by course and surface soonest due date | done-criteria: tasks under different courses appear under separate course headings; a due date set on a task is shown next to it; the site surfaces which task is due soonest across all courses; an incomplete task past its due date is visibly flagged as overdue | status: pending

## Backlog
Reminders/notifications, calendar sync, sharing tasks with classmates, file attachments on tasks, recurring tasks, a mobile app, dark mode, task priority levels, search/filter, per-course color coding, renaming a course after tasks exist under it.
